FAQ

Before you order

Do I need to write the lyrics?

No. You give us the facts, memories, phrases and feeling. We build the song from that brief.

Can I ask for a specific artist?

We can work from musical characteristics and eras, but we do not promise imitation of a living artist’s exact voice or identity.

What happens if I want a change?

The base custom song includes one revision. Premium products can include broader revision scope.

Is this site already processing payments?

Not yet. This first release is the conversion-ready front end. Secure checkout and order automation are the next integration step.
